# Clinic Genie Coordination Desk

This is an interactive demo, not a connected production application.
Read PRODUCT.md, TRACKING_RULES.md, ARCHITECTURE.md and OPERATIONS.md before changes.
Run npm test and npm run build. Preserve evidence requirements and source escaping.
Never label simulated records as live messages. Never store credentials or patient details in browser storage.
Target deployment: the user's existing Vercel account, access pending.
Do not deploy live client data without authentication and durable server storage.
Account connection and API provisioning are deferred. Do not invent a working sync or AI analysis.
