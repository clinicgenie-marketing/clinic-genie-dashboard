# Clinic Genie Coordination Desk, iteration 1

Open dist/index.html to use the interactive sample dashboard. No installation is needed.

All clinic conversations are fictional. The real business account identifiers are shown only as disconnected configuration. Edits are stored in this browser, not shared with another user. No messages are sent, no AI service is called, and no background monitoring runs.

To develop and serve locally: npm run dev. This builds the app and starts the local server at http://localhost:3000. Run npm test to execute the tests. To serve an existing build without rebuilding: npm start.

Vercel configuration and project documentation are included. Live integration is the next phase and is not part of this deliverable.
